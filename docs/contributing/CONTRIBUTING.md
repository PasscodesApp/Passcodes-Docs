# Contributing to Passcodes

Contributions to Passcodes are welcome. 💜

We intentionally keep this guide short. Rather than repeating the usual GitHub workflow, this document focuses on the things you should understand **before contributing**.

## Before You Contribute

Please read and understand these two documents:

1. **[Contribution Terms](terms-for-contributions.md)**
   These terms explain the expectations and conditions that apply to contributions made to Passcodes, including compensation, public contributions, attribution, future use, and continued availability of contributions.

2. **[MIT License](LICENSE.md)**
   This is the open-source license under which Passcodes is distributed.

By submitting a contribution, you are expected to understand and adhere to both.

## Join the Community

We use our **[Discord Community](https://discord.gg/kSSkYq7KAQ)** as the primary place for contributor communication and onboarding.

If you are interested in contributing, join the community and let us know what you would like to work on.

You can use the community to:

* ask questions about the project;
* discuss an idea before implementing it;
* get help understanding the codebase;
* find an issue or task to work on;
* get guidance through your first contribution; or
* get help from other contributors and maintainers.

## Your First Contribution

You do not need to already know the entire Passcodes codebase to contribute.

If you are new to open source or to Passcodes, **ask for guidance first**. We can help you understand where to start and how the project works. **Or, even better, use AI as your guide.**

If you already know the usual GitHub workflow, you can simply fork the repository, make your changes, and open a pull request.

If you are not familiar with the process, don't worry — ask in the community and we can guide you through it.

## That's It

There is no need to memorize a long list of contribution rules.

`Just remember to be "good", don't make a mess, and you'll be fine.`

**Read the [Contribution Terms](terms-for-contributions.md), read the [MIT License](LICENSE.md), and join the [Discord Community](https://discord.gg/kSSkYq7KAQ).**

From there, we'll help you get started. 💜
